# Troubleshooting

## Сборка APK

### JDK 25 / "Unsupported class file major version"

**Проблема:** Установлен JDK 25, который несовместим с Kotlin 1.9.22.

**Решение:**
```powershell
# Установить JDK 21
$env:JAVA_HOME = "$env:USERPROFILE\.jdks\jdk-21.0.12+8"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\gradlew.bat clean assembleDebug
```

### "Could not resolve kotlin-stdlib"

**Проблема:** Нет интернета при первой сборке.

**Решение:** Подключитесь к интернету. Gradle скачивает зависимости автоматически.

### "Compose compiler requires Kotlin X.Y"

**Проблема:** Версия Kotlin изменена вручную.

**Решение:** Не редактируйте `build.gradle`. Kotlin 1.9.22 зафиксирован для совместимости с Compose compiler 1.5.8.

## ADB

### "unable to connect to 192.168.2.xxx:5555"

**Причины:**
1. ADB не включён на TV
2. TV и компьютер в разных подсетях
3. Брандмауэр блокирует порт 5555

**Решение:**
```bash
# 1. Проверьте IP TV: Настройки → Сеть
# 2. Убедитесь что TV и компьютер в одной Wi-Fi сети
# 3. Попробуйте: adb kill-server && adb start-server
# 4. На Sony: ADB-отладка должна быть включена вручную
```

### "error: device unauthorized"

**Решение:** На TV должно появиться окно "Разрешить отладку по USB?" → OK. Если не появляется:
1. Отключите ADB
2. Перезагрузите TV
3. Включите ADB заново

## Заставка

### Заставка не запускается

**Проверьте:**
1. VPN Monitor установлен как заставка: Настройки ТВ → Заставка → VPN Monitor
2. Время бездействия установлено (5-15 минут)
3. Приложение запущено хотя бы один раз

### Заставка показывает "offline" для серверов

**Причины:**
1. Роутер недоступен
2. vpn_monitor.py не запущен на роутере
3. Неправильный IP роутера в настройках

**Решение:**
```bash
# 1. Проверьте доступность роутера
curl -s http://192.168.2.1:17463/api/status

# 2. Если 404 — перезапустите vpn_monitor.py
ssh root@192.168.2.1
kill $(pidof python3)
cd /etc/vpn-monitor && nohup python3 vpn_monitor.py > /tmp/vpn_monitor.log 2>&1 &

# 3. Проверьте логи
tail -20 /tmp/vpn_monitor.log
```

### Заставка показывает пустой экран

**Причина:** Нет серверов или все отключены.

**Решение:** Добавьте серверы через веб-дашборд или подписку.

## Оверлей

### Оверлей не отображается

**Проверьте:**
1. Разрешение "Отображение поверх других приложений" включено
2. Оверлей включён в настройках приложения
3. Хотя бы один сервер добавлен

### Sony BRAVIA: при нажатии OK вылезает меню

Это **не баг** приложения. Это поведение лаунчера Sony:
- При нажатии OK на карточке VPN Monitor → Sony показывает контекстное меню
- Приложение при этом работает нормально

**Обходной путь:** Используйте ADB для запуска:
```bash
adb shell am start -n com.vpnmonitor.tv/.MainActivity
```

## Веб-дашборд

### 404 на корневом пути (`/`)

**Причина:** `api_server.py` повреждён (потеряны роуты).

**Решение:** Восстановите файл `api_server.py` из репозитория и перезапустите.

### Кнопки не работают (JS ошибки)

**Причина:** Ошибка JavaScript в `index.html`.

**Решение:** Проверьте консоль браузера (F12). Если ошибка в `};` — исправьте多余的 точку с запятой.

## Подписки

### "No valid servers found in subscription"

**Причины:**
1. URL подписки недоступен
2. Файл подписки пустой
3. Формат не base64 и не plain text

**Проверьте:**
```bash
curl -s https://your-sub-url | head -5
# Должны увидеть строки vless://, vmess://, trojan://
```

### Подписка парсится, но серверы не добавляются

**Проверьте:**
1. Выбраны ли серверы в модалке парсинга
2. Нажата ли кнопка "Добавить выбранные"

## Серверы

### "HTTP 000" ошибка при проверке

**Причины:**
1. Сервер недоступен из сети роутера
2. plink не установлен на роутере
3. Неверные SSH-credentials

**Решение:** Проверьте plink на роутере:
```bash
which plink || opkg install plink
```

### Пинг = 0

**Причина:** Пинг не измеряется (сервер не отвечает на ICMP или TCP connect timeout).

**Нормально для:** VLESS-серверов, которые блокируют ICMP.
