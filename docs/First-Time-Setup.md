# Первоначальная настройка

## Шаг 1: Запустите приложение

Откройте **VPN Monitor** из лаунчера Android TV.

## Шаг 2: Укажите URL роутера

На главном экране введите адрес вашего роутера:

```
http://192.168.2.1:17463
```

Если роутер работает на другом IP, подставьте его. Приложение автоматически попробует:
1. Кеш (последний известный адрес)
2. Wi-Fi шлюз (автопоиск)
3. Дефолт (`192.168.1.1:17463`)

## Шаг 3: Сохраните настройки

Нажмите **"Сохранить"**. Приложение проверит связь с роутером и зарегистрирует ТВ как устройство.

## Шаг 4: Разрешите оверлей

1. Настройки ТВ → Приложения → Special app access (Особый доступ)
2. **Display over other apps** (Отображение поверх других приложений)
3. Найдите **VPN Monitor** → Вкл

## Шаг 5: Настройте заставку

1. Настройки ТВ → **Screen saver** (Заставка)
2. Выберите **VPN Monitor**
3. Время до запуска: 5-15 минут

## Шаг 6: Добавьте серверы

### Через веб-дашборд
Откройте `http://192.168.2.1:17463` на любом устройстве в сети.

### Через подписку
1. Найдите кнопку **"Подписка"** в настройках
2. Вставьте URL подписки (начинается с `https://`)
3. Выберите серверы для добавления
4. Нажмите **"Добавить"**

### Вручную
В веб-дашборде: **"Добавить сервер"** → заполните форму (имя, хост, порт, протокол, UUID).

## Шаг 7: Проверьте

- Откройте веб-дашборд → серверы отображаются с их статусами
- На ТВ: заставка покажет статусы серверов через указанное время бездействия
- На ТВ: оверлей показывает компактную информацию о серверах

## Автосинхронизация подписок

Подписки автоматически синхронизируются каждые 10 минут. Новые серверы из подписки появятся в списке автоматически.
