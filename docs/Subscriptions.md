# Подписки

Подписки позволяют автоматически добавлять и обновлять серверы из URL.

## Как это работает

1. Вы вставляете URL подписки (например, `https://example.com/sub/vless`)
2. Приложение скачивает файл подписки
3. Файл декодируется (обычно base64) и парсится на отдельные URI (`vless://`, `vmess://`, `trojan://`)
4. Отображается список найденных серверов с чекбоксами
5. Вы выбираете нужные серверы и добавляете

## Добавление подписки

### Через веб-дашборд

1. Откройте `http://192.168.2.1:17463`
2. Найдите раздел **"Подписки"**
3. Нажмите **"Добавить подписку"**
4. Вставьте URL → **"Парсить"**
5. Выберите серверы → **"Добавить выбранные"**

### Через API

```bash
# Добавить подписку в список отслеживания
curl -X POST http://192.168.2.1:17463/api/subscriptions \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/sub/vless"}'

# Парсить URL и получить серверы
curl -X POST http://192.168.2.1:17463/api/parse-uri \
  -H "Content-Type: application/json" \
  -d '{"uri": "https://example.com/sub/vless"}'
```

## Автосинхронизация

Checker автоматически обновляет подписки перед каждой проверкой:

1. Скачивает все подписки из таблицы `subscriptions`
2. Парсит серверы
3. Добавляет новые серверы (которых ещё нет по `host:port`)
4. Записывает `last_sync` и `last_count`

Интервал синхронизации = интервал проверки (по умолчанию 300 секунд).

## Форматы подписок

### Base64-кодированный список

Самый распространённый формат. Содержимое файла — base64-строка, которая при декодировании даёт:

```
vless://uuid1@host1:443#name1?type=tcp&...
vless://uuid2@host2:443#name2?type=tcp&...
vmess://base64json...
trojan://pass@host3:443#name3?...
```

### Прямой список

Некоторые подписки отдают plain-text список URI без base64.

## Удаление подписки

```bash
# Через веб-дашборд: кнопка "Удалить" рядом с подпиской

# Через API
curl -X DELETE http://192.168.2.1:17463/api/subscriptions/1
```

## Просмотр подписок

```bash
curl -s http://192.168.2.1:17463/api/subscriptions | python3 -m json.tool
```

Ответ:
```json
[
  {
    "id": 1,
    "url": "https://example.com/sub/vless",
    "last_sync": "2026-08-21T10:00:00",
    "last_count": 15,
    "enabled": 1
  }
]
```
