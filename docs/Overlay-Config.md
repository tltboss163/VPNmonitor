# Настройка оверлея

Оверлей показывает статусы VPN-серверов поверх любого приложения на Android TV.

## Включение

1. Настройки ТВ → **Special app access → Display over other apps**
2. Найти **VPN Monitor** → **Вкл**
3. В приложении VPN Monitor → **"Показывать оверлей" → Вкл**

## Параметры

### Позиция

| Позиция | Описание |
|---------|----------|
| top-left | Верхний левый угол |
| top-right | Верхний правый угол |
| bottom-left | Нижний левый угол |
| bottom-right | Нижний правый угол (по умолчанию) |

### Размер

| Размер | Ширина (приблизительно) |
|--------|------------------------|
| small | ~320px |
| medium | ~480px |
| large | ~640px |

### Прозрачность

Значение от 0.1 (почти невидимый) до 1.0 (полностью непрозрачный).

### Дополнительные параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| show_location | Вкл | Показывать локацию сервера |
| show_ping | Вкл | Показывать пинг в ms |
| show_vless | Вкл | Показывать VLESS статус |

## Настройка через веб-дашборд

1. Откройте `http://192.168.2.1:17463`
2. **Настройки** → форма оверлея
3. Измените параметры
4. Нажмите **"Сохранить"**

Настройки применяются к оверлею на всех устройствах в реальном времени.

## Настройка через API

```bash
# Получить текущие настройки
curl -s http://192.168.2.1:17463/api/settings

# Сохранить настройки
curl -X POST http://192.168.2.1:17463/api/settings \
  -H "Content-Type: application/json" \
  -d '{
    "position": "top-right",
    "size": "medium",
    "opacity": 0.3,
    "show_location": 1,
    "show_ping": 1
  }'
```

## Устройства

Оверлей работает как Foreground Service:

```
OverlayService (FOREGROUND_SERVICE)
├── TYPE_SYSTEM_ALERT (окно поверх приложений)
├── Обновление каждые 10 секунд (HTTP → /api/status)
├── Анимация пульсации для статусов (up/down/degraded)
└── Звук алерта при деградации (если включён)
```

## Звук алерта

Для настройки звука при обнаружении проблем:

1. Подготовьте MP3/WAV файл (1-2 секунды)
2. Переименуйте в `alert_sound.wav`
3. Поместите в `app/src/main/res/raw/alert_sound.wav`
4. Пересоберите APK
5. В настройках включите **"Звук алерта"**
