# Установка на Android TV

## Включите ADB на TV

### Sony BRAVIA
1. **Настройки → Система → О разработчике**
2. **ADB-отладка → Вкл**
3. Если пункт "О разработчике" не виден:
   - **Настройки → Система → О телевизоре**
   - Нажмите OK 5 раз на **"Версия ПО"**
   - Вернитесь назад — пункт "О разработчике" появится

### MiTV (Xiaomi)
1. **Настройки → О телевизоре**
2. Нажмите OK 5 раз на **"Версия"**
3. Вернитесь: **Разработчик → ADB-отладка → Вкл**

### Другие Android TV
1. **Настройки → О телевизоре → Номер сборки** (нажать 5-7 раз)
2. **Настройки → Разработчик → ADB-отладка → Вкл**

## Установка APK

### Через Wi-Fi ADB

```bash
# 1. Узнайте IP TV (Настройки → Сеть → О Wi-Fi)
# MiTV:    192.168.2.132
# Sony:    192.168.2.193

# 2. Подключиться
adb connect 192.168.2.132:5555

# 3. Проверить подключение
adb devices
# Должно показать: 192.168.2.132:5555    device

# 4. Установить APK
adb install app\build\outputs\apk\debug\app-debug.apk
# Или обновить существующую установку:
adb install -r app\build\outputs\apk\debug\app-debug.apk

# 5. Запустить
adb shell am start -n com.vpnmonitor.tv/.MainActivity
```

### Через USB

```bash
# 1. Подключите TV к компьютеру USB-кабелем
# 2. На TV: "Разрешить отладку по USB?" → OK
# 3. Установить
adb install app-debug.apk
```

## Удаление APK

```bash
adb uninstall com.vpnmonitor.tv
```

## Первичная настройка

1. Запустите **VPN Monitor** из лаунчера ТВ
2. Введите **URL роутера**: `http://192.168.2.1:17463` (или ваш IP)
3. Нажмите **"Сохранить"**
4. Приложение автоматически зарегистрирует ТВ как устройство

### Разрешение оверлея
5. Настройки Т� → **Приложения → VPN Monitor → Разрешения → Отображение поверх**
6. Включите **"Разрешить поверх других приложений"**

### Настройка заставки
7. **Настройки ТВ → Экран → Заставка → VPN Monitor**
8. Заставка будет запускаться при бездействии

### Включение оверлея
9. В приложении: **"Показывать оверлей" → Вкл**
10. Настраиваем позицию, размер, прозрачность

## Удалённая установка (все ТВ сразу)

```powershell
$devices = @("192.168.2.132:5555", "192.168.2.193:5555")
foreach ($dev in $devices) {
    adb connect $dev
    adb -s $dev install -r app\build\outputs\apk\debug\app-debug.apk
}
```
