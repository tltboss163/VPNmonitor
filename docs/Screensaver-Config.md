# Настройка заставки

Заставка (Screensaver) показывает статусы VPN-серверов поверх анимированного фона.

## Режимы фона

| Режим | Описание |
|-------|----------|
| `status` (по умолчанию) | Анимированные градиенты (тёмная тема) |
| `images` | Слайд-шоу картинок (кастомные URL или waifu.pics API) |
| `video` | Видео-фон через ExoPlayer (H.264 MP4, loop) |

### Настройка через веб-дашборд

1. Откройте `http://192.168.2.1:17463`
2. **Настройки → Режим заставки**
3. Выберите режим
4. Для `images`: добавьте URL картинок
5. Для `video`: добавьте MP4 URLs в плейлист

### Настройка через Android TV

В приложении VPN Monitor:
- **Режим заставки**: градиент / картинки / видео
- **Плейлист видео**: список URL через запятую
- **Звук видео**: вкл/выкл

## Адаптивная сетка

Заставка автоматически подстраивает количество колонок:

| Кол-во серверов | Колонки |
|-----------------|---------|
| 1-2 | 1 (полная ширина) |
| 3-4 | 2 |
| 5-8 | 3 |
| 9+ | 4 |

При 3+ колонках карточки переключаются в компактный вид:
- Имя сервера (1 строка)
- Локация (1 строка)
- VLESS + Пинг (бейджи)

## Видео-фон

### Требования к видео
- Формат: MP4 (H.264)
- Разрешение: до 4K (автоматическая адаптация)
- Зацикленное воспроизведение (loop)

### Встроенные ролики

Если плейлист пуст, используются встроенные URL:
1. Tenor GIF-циклы (лёгкие, 2-5 сек)
2. archive.org тизеры
3. DesktopHut HD-обои (4K)

### Транскодинг на роутере

Для больших файлов роутер может транскодировать видео в H.264 MP4:

```bash
# Подготовить видео
curl -X POST http://192.168.2.1:17463/api/media/prepare \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/video.mkv"}'

# Проверить статус
curl "http://192.168.2.1:17463/api/media/status?url=https%3A%2F%2Fexample.com%2Fvideo.mkv"
```

## Debug-заставка

`ScreensaverDebugActivity` позволяет тестировать заставку без ожидания бездействия:

```bash
adb shell am start -n com.vpnmonitor.tv/.ScreensaverDebugActivity
```

На экране Debug:
- Статусы серверов в реальном времени
- Кнопки для переключения фона (D-Pad: вверх/вниз)
- Часы
