# Android TV VPN Monitor — Compose for TV

Красивое приложение для мониторинга VLESS/XHTTP подключений на Android TV, построенное на **Jetpack Compose for TV**.

## Дизайн

- 🎨 **Тёмная тема** с градиентами (indigo → purple → pink)
- ✨ **Анимированные индикаторы** статуса с пульсацией
- 🌊 **Анимированный фон** в screensaver с движущимися градиентами
- 🎯 **Фокус-эффекты** для навигации пультом (scale, glow)
- 🔢 **Анимированные счётчики** с slide-переходами
- 💫 **Blur и glassmorphism** в оверлее

## Скриншоты (описание)

### Экран настроек
- Градиентный заголовок "🔒 VPN Monitor"
- Карточки с закруглёнными углами и glow-бордерами при фокусе
- Текстовые поля с анимацией scale при фокусе
- Кнопки с эффектом приподнятия при наведении

### Оверлей
- Полупрозрачная карточка с вертикальным градиентом
- Пульсирующие индикаторы статуса (зелёный/жёлтый/красный)
- Компактное отображение: имя + локация + VLESS статус + пинг
- Настраиваемая прозрачность, позиция (4 угла), размер

### Заставка (Screensaver)
- Чёрный фон с анимированными градиентными кругами
- Градиентный заголовок
- Список серверов в стильных карточках
- Сводка: VLESS OK / Degraded / Down с анимированными счётчиками

## Сборка

### Требования
- Android Studio Hedgehog (2023.1.1) или новее
- Android SDK 34
- Kotlin 1.9+
- Jetpack Compose 1.5+

### Сборка APK

```bash
cd android-tv
./gradlew assembleDebug
```

### Установка на TV

```bash
adb connect IP_ВАШЕГО_ТВ:5555
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Настройка

1. Откройте **VPN Monitor** в лаунчере ТВ
2. Введите URL роутера (`http://192.168.1.1:17463`) и **API Key**
3. Включите **«Показывать оверлей»** — дайте разрешение на отображение поверх приложений
4. В настройках ТВ выберите **VPN Monitor** как заставку

## Звук алерта

1. Подготовьте MP3 файл (короткий, 1-2 сек)
2. Переименуйте в `alert_sound.mp3`
3. Поместите в `app/src/main/res/raw/alert_sound.mp3`
4. Пересоберите APK

## Разрешения

- `SYSTEM_ALERT_WINDOW` — оверлей поверх приложений
- `FOREGROUND_SERVICE` — фоновая работа
- `INTERNET` — связь с роутером
- `RECEIVE_BOOT_COMPLETED` — автозапуск оверлея

## Управление пультом

- **D-Pad** — навигация
- **OK** — выбор/подтверждение
- **Back** — назад
- Фокус автоматически переключается между элементами
